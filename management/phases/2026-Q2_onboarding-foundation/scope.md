# Dentro de Alcance

- alta y acceso inicial
- manejo básico de errores de autenticación
- primera pantalla o paso guiado tras login
- trazabilidad mínima en analytics y logs

# Fuera de Alcance

- billing
- onboarding multi-rol
- migraciones de usuarios legacy
- sistema avanzado de permisos

# Criterio de Corte

Si una tarea no mejora acceso inicial, activación temprana o trazabilidad básica del onboarding, sale de esta fase.
