# Agent Operating Rules

> Contrato operativo para Claude, Codex y otros agentes del proyecto.

## Secuencia de arranque

1. Leer `PROJECT_MAP.md`.
2. Identificar fase o documento objetivo.
3. Leer `management/phases/{phase}/brief.md` y `status.md` si aplica.
4. Leer PRD, flow o ADR canónico relacionado.
5. Leer `DOCUMENTATION_RULES.md` si se va a tocar documentación.

## Reglas

1. Escribir en la carpeta correcta.
2. No duplicar decisiones entre `product/`, `management/` y `docs/`.
3. No tratar transcripciones como verdad canónica final.
4. No editar `design-context/` directamente.
5. Enlazar documentos relacionados.
