# New Project Checklist

> Checklist operativo para inicializar un proyecto nuevo desde este template.

## Base

- [ ] Copiar el contenido de `V0.2` al nuevo proyecto
- [ ] Revisar `README.md`
- [ ] Sustituir placeholders globales
- [ ] Confirmar naming de fases, features y flows

## Documentación de entrada

- [ ] Editar `PROJECT_MAP.md`
- [ ] Editar `CLAUDE.md` si hace falta contexto específico adicional
- [ ] Editar `AGENTS.md` si hay reglas multiagente especiales
- [ ] Revisar `DOCUMENTATION_RULES.md`
- [ ] Revisar `FRONTMATTER_SPEC.md`

## Producto

- [ ] Crear o adaptar `product/definition.md`
- [ ] Crear o adaptar `product/roadmap.md`
- [ ] Crear primer `prd.md` o `overview.md` real

## Gestión

- [ ] Renombrar o recrear la primera fase en `management/phases/`
- [ ] Completar `brief.md`
- [ ] Completar `scope.md`
- [ ] Completar `plan.md`
- [ ] Limpiar `status.md` de datos ficticios

## Técnica

- [ ] Revisar `docs/architecture/overview.md`
- [ ] Sustituir o borrar ADRs de ejemplo que no apliquen
- [ ] Revisar `docs/traceability/README.md`

## GitHub y operación

- [ ] Revisar issue templates
- [ ] Definir estrategia de automatización para `PROJECT_MAP.md`
- [ ] Definir estrategia de automatización para `status.md`
- [ ] Decidir qué validará CI sobre frontmatter y enlaces

## Cierre

- [ ] Buscar placeholders restantes
- [ ] Verificar enlaces internos principales
- [ ] Confirmar primera ruta de lectura para agentes
