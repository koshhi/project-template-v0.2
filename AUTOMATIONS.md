# Automations

> Qué conviene automatizar para que el scaffold no dependa de disciplina manual.

Automatizaciones mínimas:
- regenerar `PROJECT_MAP.md`
- sincronizar `management/phases/*/status.md`
- validar frontmatter
- sincronizar `design-context/` desde `design/`

Scripts sugeridos:
- `scripts/generate-project-map.js`
- `scripts/sync-phase-status.js`
- `scripts/validate-frontmatter.js`
- `scripts/sync-design-context.js`
